# ReadHaven

ReadHaven is a book management platform where users can browse, add, and manage books in a user-friendly interface. The platform supports Google authentication for user login and utilizes MongoDB as the backend database for storing product details.

---

## Live Link

You can visit the live site at [ReadHaven](https://read-haven.vercel.app/).

---

## GitHub Repository

The source code for this project is available on GitHub: [https://github.com/santuchy/Read-Haven](https://github.com/santuchy/Read-Haven).

---

## Requirements

- **Node.js** (v16 or later)
- **MongoDB Atlas** (for database)
- **Vercel** (for deployment)
- **Google Cloud Account** (for Google OAuth)
